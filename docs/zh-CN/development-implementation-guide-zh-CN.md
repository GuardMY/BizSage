## 第一部分：分阶段落地规划

### 1.1 总体阶段划分（MVP → V1 → V2 → V3）

整体分三阶段迭代：MVP 基础可用版（V1 迭代）→ 生产工程高可用版（V2 迭代）→ 全域完整商业化终版（V3 迭代）。

每层架构模块严格遵循九层全域分层：运维底座层 → 数据采集层 → 数据治理层 → 知识中台层 → RAG 检索层 → 大模型推理层 → 双 Agent 核心层 → 商业化服务层 → 终端输出层。

所有开发任务区分 P0（必做、上线硬性门槛）、P1（重要业务）、P2（优化增强、延后迭代）。

每阶段附带完整验收指标、SLA 标准、测试范围、运维配套方案，AI 开发 Agent 可按章节逐条拆解编码任务。

#### 迭代阶段划分总览

| 迭代版本 | 阶段定位 | 核心交付价值 | 核心新增模块 | 上线门槛 |
|---|---|---|---|---|
| **迭代 V1：MVP 最小可用版** | 内部验证、业务闭环跑通 | 基础数据采集 + 基础知识库 + 单 Agent 基础对话 + 简易前端 | 四层采集源、基础数据治理、静态知识库、基础 RAG、经营诊断 Agent 极简版、基础对话前端、基础网关 | 可完成基础经营问诊、基础情报采集入库，无高可用、无完整商业化、无容灾 |
| **迭代 V2：生产高可用工程版** | 正式对外灰度、满足生产稳定要求 | 补齐全底层工程能力、完善 AI 推理能力、完善权限体系 | 运维底座全能力、增量爬虫/熔断/死信、多级缓存、灾备备份、多模型路由、推理自检、完整 RBAC 权限、基础报告导出 | 全链路监控告警、数据容灾、故障自愈、接口限流、合规脱敏完整落地，可小规模付费用户灰度 |
| **迭代 V3：全域商业化封顶终版** | 全量商业化上线、完整产品闭环 | 补齐全部上层业务、壁垒能力、商业化变现、完整安全体系 | 时序快照、动态信源权重、双 Agent 完整能力、智能报告引擎、用户画像、多租户四层隔离、完整安全风控、全终端适配、完整运维台账 | 满足等保、完整付费会员体系、全套商业交付能力、99.9% 可用性 SLA，全量对外开放运营 |

#### 统一开发约束（全三阶段通用，AI 开发 Agent 强制遵循）

1. **数据规范**：所有数据必须携带行业 ID、链路 ID、地域、置信度、来源标签；用户隐私数据必须脱敏，禁止明文持久化。
2. **接口规范**：统一 API 网关出入参格式、统一错误码、统一日志埋点、统一鉴权逻辑。
3. **AI 约束**：无知识库依据禁止生成主观结论，输出必须挂载溯源、免责、时效标注。
4. **存储规范**：冷热分层设计，热数据 MySQL，冷数据对象存储，向量单独向量库。
5. **运维规范**：所有模块埋点监控指标、异常告警、操作日志留存 ≥6 个月。
6. **兼容规范**：所有迭代向下兼容，灰度发布，支持一键回滚。

### 1.2 9 层架构每层优先级矩阵（P0/P1/P2）

#### 01. 运维工程底座层

**V1（P0 必做）：**
- 基础 Redis 单机缓存（仅缓存热点知识库，多级缓存集群延后 V2）
- 基础日志收集（本地 + 简易 ELK，无审计分层日志）
- 基础单机定时任务调度（XXL-JOB 单机部署，无弹性伸缩）
- 基础接口限流、简单熔断（无死信队列、无降级策略）

**P1/P2（延后至 V2/V3）：** 弹性伸缩、异地灾备、冷热存储、数据血缘、多环境隔离、成本管控、监控大盘全部延后。

**V2 新增 P0：**
- 多级 Redis 缓存四层架构：爬虫页面缓存、API 缓存、知识库全局缓存、局部维度缓存
- 分布式集群弹性伸缩：任务堆积自动扩容、低峰缩容、故障节点自愈
- 完整熔断/降级/死信队列：爬虫分级重试、指数退避、域名熔断、死信分类归档
- 灾备恢复机制：每日全量 + 增量备份、本地备份校验、单库故障恢复预案
- 四套环境物理隔离：开发/测试/预发/生产独立资源，发布灰度流程
- 全链路监控指标大盘、三级分级告警（企业微信 + 短信）
- 基础 SLA 指标统计、自动化运维日报台账

**V3 新增：**
- 全链路资源成本自动统计台账：代理、API、服务器、存储月度账单分析
- 爬虫完整安全攻防细则：请求指纹随机化、封禁分级处置、合规抓取兜底
- 完整 SLA 量化指标监控大屏，自动生成月度可用性报告
- 标准化运维交付资产：灾备操作手册、故障应急预案、压测报告模板
- 全环境发布管控：灰度分批发布、双审核、一键回滚流程

#### 02. 多源数据采集层

**V1（P0 必做）：**
- 用户私有经营数据采集：对话分步采集、Excel 导入、基础 AES 加密存储、简单隐私脱敏
- 人工本地化情报采集：录入表单、单人审核（双人复核 V3）、基础入库隔离
- 自研分布式爬虫集群基础版：基础抓取、静态页面 Aiohttp、基础布隆去重；无增量、无分级重试、无熔断、无死信、代理池单厂商
- 第三方 API 采集基础版：单厂商 API、无多厂商容灾、无缓存兜底、无时序快照

**P1/P2（延后）：** 增量抓取、IP 轮换、故障切换、API 缓存、成本管控全部延后。

**V2 新增 P0：**
- 爬虫增量抓取机制：MD5 页面指纹、SimHash 正文变更检测，无变更跳过抓取
- 爬虫安全攻防：海量 UA 池、请求头随机抖动、间隔随机偏移、封禁分层处置
- 多厂商代理池自动轮换、IP 冷却机制
- 第三方 API 多厂商冗余、自动故障切换、API 缓存控成本、时序快照兜底
- 采集全链路日志埋点，统计抓取成功率、API 调用量、缓存命中率

#### 03. 全域数据治理层

**V1（P0 必做）：**
- 字段归一化、基础正文抽取、URL 布隆 + SimHash 双重去重
- 简易风控：基础谣言关键词过滤，无七层冲突比对算法
- 固定静态权重（100%/85%/60%/35%/10% 写死配置，动态权重算法 V3）
- 基础入库锁，无版本合并、无时序快照生成

**P1/P2（延后）：** 动态权重、时序快照、知识库并发锁、垃圾数据自动治理延后。

**V2 新增 P0：**
- 新旧信息七层冲突比对完整风控引擎，区分波动/特例/永久迭代/存疑工单
- 时序版本快照：日/周/月快照自动生成，存入冷存储
- 知识库行级乐观锁，多源内容智能合并，杜绝覆盖错乱
- 四层多租户基础数据隔离：用户私有隔离、地域隔离、行业隔离

**V3 新增：**
- 动态信源权重实时计算引擎，五大维度自动升降权，替代固定权重
- 全链路数据血缘追溯体系，每条情报携带完整血缘 ID，逆向溯源采集-清洗-入库-推理全链路
- 自动垃圾数据定时治理：过期死信、废弃缓存、冗余快照、测试脏数据自动清理
- 冷热存储分层完整规范：热/温/冷数据自动迁移策略，控制存储成本

#### 04. 智能知识中台层

**V1（P0 必做）：**
- 静态行业基线知识库：结构化 MySQL 存储，基础人工录入/批量导入
- 基础向量库构建：知识库批量向量化存储
- 简易知识精炼：基础去重合并，无标准化标签体系

**P1/P2（延后）：** 动态实时情报独立库、时序版本库、完整知识生命周期管理延后。

**V2 新增 P0：**
- 动态实时情报独立知识库，实时增量入库参与推理
- 独立时序版本知识库存储快照，支持历史回溯查询
- 完整 AI 知识精炼引擎：自动标签、同源合并、过期淘汰
- 完整知识生命周期管理链路

#### 05. 多级 RAG 检索增强层

**V1（P0 必做）：**
- 关键词检索 + 向量语义检索双模式
- 基础重排序（仅信源权重排序，无时效/地域/行业融合）
- 基础上下文截断，无智能摘要压缩
- 简易防幻觉：无依据标注信息不足

**P1/P2（延后）：** 时序回溯、地域/行业/会员权限过滤、多维度融合重排延后。

**V2 新增 P0：**
- 时序回溯检索、地域过滤、行业过滤、会员权限分级检索
- 六维度权重融合重排序算法（时效/地域/行业/置信度等）
- 上下文智能压缩、超长内容自动摘要，解决上下文溢出
- 完整防幻觉约束机制，冲突内容强制标注存疑

#### 06. 大模型推理服务层

**V1（P0 必做）：**
- 固定单一大模型提供推理能力
- 基础通用 Prompt 模板（角色 + 合规）
- 简单超时兜底（静态缓存）

**P1/P2（延后）：** 多模型智能路由、五层推理自检、全套分层 Prompt、多级降级延后。

**V2 新增 P0：**
- 多模型智能路由：轻量/均衡/高阶/任务小模型自动分发
- 推理输出五道自检：事实/时效/地域/逻辑/合规校验，不合格重推
- 全套分层标准化 Prompt 库（角色/行业/地域/合规/输出格式）
- 多层推理降级：缓存兜底、预置标准答案、限流排队提示

#### 07. 双 Agent 智能业务核心层

**V1（P0 必做）：**
- 经营诊断 Agent 基础链路：用户提问 → RAG 检索 → 推理输出
- 基础加权推理规则（固定权重）
- 短期会话记忆，无长期用户画像记忆
- 输出基础溯源 + 免责标注

**P1/P2（延后）：** 入行学习 Agent、三级完整记忆、标准化结构化输出延后。

**V2 新增 P0：**
- 入行学习 Agent 完整基础能力：行业科普、政策解读、循序渐进教学
- Agent 三级记忆体系：短期会话记忆 + 长期用户画像记忆 + 90 天自动遗忘
- 双 Agent 互通跳转：诊断一键跳转学习、学习一键问诊诊断
- 输出标准化统一模板：溯源、时效、置信、免责固定排版

#### 08. 商业化业务服务层

**V1（P0 必做）：**
- 基础会话管理：新建/归档对话
- 简易 RBAC：超级管理员、普通运营、普通用户三角色，无分层数据权限
- 基础意图识别（仅区分问诊/闲聊）

**P1/P2（延后）：** 报告生成引擎、完整用户画像、多层 RBAC、会员权限、投稿激励体系延后。

**V2 新增 P0：**
- 简易报告生成引擎：经营诊断 PDF 报告导出，带溯源与免责
- 完整 RBAC 双层权限：功能权限 + 基础数据权限，隔离付费/免费情报
- 用户基础画像标签：行业、地域、会员等级、咨询偏好
- 用户投稿激励基础流程：预发放会员时长，复核生效

**V3 新增：**
- 全五类标准化报告完整生成引擎：科普/市场调研/诊断/专题风险/周期复盘报告
- 精细化用户画像全标签体系，用于个性化推送、精准运营
- 完整付费会员体系：免费/普通付费/高阶付费三层权限隔离，付费情报独立分库
- 用户投稿完整激励运营体系，自动结算会员时长、投稿排行榜
- 完整订单、会员、权益后台管理模块

#### 09. 终端展示与输出层

**V1（P0 必做）：**
- Web 端对话交互页面：流式输出、溯源弹窗展示
- 简易运营后台：情报录入、情报列表、用户列表

**P1/P2（延后）：** PDF 报告导出、完整监控大盘、移动端适配、付费会员前台全部延后。

**V2 新增 P0：**
- 标准化 PDF 报告导出功能，自动封面、目录、溯源列表
- 完整运维监控后台大盘，查看爬虫、API、知识库指标
- 情报复核工单管理页面，处理冲突存疑数据

**V3 新增：**
- H5 移动端完整适配，弱网降级、轻量化加载
- 完整前台会员中心、权益查看、历史对话、报告下载页面
- 全链路审计日志查询后台，支持按流水号、用户、时间检索
- 自动化月度运营报表导出：情报增量、用户量、付费转化、告警统计

1. 统一网关前置鉴权、限流、日志埋点，所有接口统一返回体结构。
2. 所有查询接口强制携带用户行业、地域、会员等级过滤条件，自动隔离数据。
3. 写入接口加乐观锁，防止并发覆盖数据。
4. 异常统一捕获，分级错误码，完整异常日志上报监控。

#### AI 模块开发强制规范

1. RAG 检索必须携带权限过滤条件，免费用户过滤付费情报。
2. 模型输出必须执行五道自检，自检失败重新推理 3 次，仍失败返回信息存疑。
3. 所有 AI 输出拼接固定头部免责、尾部溯源标注，不可省略。
4. 禁止模型直接读取用户原始明文经营数据，脱敏后再传入 Prompt。

#### 测试与上线 Agent 参考标准

1. 单元测试覆盖率 ≥ 80%（P0 核心模块 100%）。
2. 每迭代必须执行：功能测试、并发压测、故障降级测试、安全越权测试。
3. 上线流程：开发 → 测试 → 预发灰度 → 生产分批发布 → 监控观察 3 小时 → 全量上线。
4. 上线后监控指标连续 3 小时无异常才算交付完成。

## 第二部分：17 模块开发规范

### 2.1 文档总则与整体业务闭环

#### 项目核心定义

本平台为面向创业者的双模式智能 Agent 工具，三大核心模块协同运行，六维信息输入支撑 AI 推理。

**六维信息源优先级权重（AI 推理强制排序，不可调整）：**

1. **用户一手经营输入数据**（最高权重，个性化诊断核心依据）
2. **本地人工扫盲情报/付费圈层情报**（地域线下真实信息）
3. **S/A 级权威实时抓取情报**（官方、权威媒体、行业协会）
4. **B 级垂直行业资讯**（仅作辅助参考）
5. **C/D 级自媒体社群信息**（仅归档，不参与风险/机遇研判）
6. **静态行业标准化知识库**（行业基础基线，用于对比校验）

#### 核心业务闭环

1. **新手用户**：入行 Agent 读取静态知识库 + 实时情报，分步教学行业全链路，生成行业学习报告。
2. **在营商家**：诊断 Agent 采集用户经营一手数据，联动本地情报、人工扫盲信息，定位经营短板，输出分级优先级整改方案。
3. **情报引擎** 7×24 小时主动全网采集信息，经清洗、NLP 解析、真伪校验、冲突校验、风险研判后同步至公共知识库。
4. **风控子系统**并行两道校验：恶意造谣拦截、新旧信息冲突甄别，过滤无效/虚假/过时数据。
5. **人工运营**补充机器盲区：本地实地扫盲、付费行业情报入库，补齐区域性、线下圈层信息。
6. **全链路风控兜底**：法律、技术、商业、运营风险内置拦截逻辑，所有输出强制挂载免责、信息标注话术。
7. **全流程日志留存**，支持人工复核、数据回溯、故障排查、合规举证。

#### 统一开发约束规则

1. 所有行业统一底层七链路标准：原材料 → 生产加工 → 品控质检 → 仓储库存 → 物流运输 → 渠道运营 → 销售回款。
2. 所有情报、知识库内容必须绑定「行业 ID、链路节点 ID、地域标签、置信度、信息类型」五维标签。
3. 所有 AI 输出禁止无依据凭空生成，必须关联对应数据源 ID，无权威佐证自动标注信息盲区。
4. 所有敏感数据（用户经营利润、联系方式、供应商底价）后端强制 AES 加密存储，前端脱敏展示。
5. 所有定时任务、抓取任务、AI 推理任务增加失败重试、告警、日志记录机制。
6. 合规强制要求：政府封锁/下架信息不采集、不推演、不猜测，前台统一公示盲区话术。

### 2.3 模块1：入行认知Agent 完整开发规范

#### 产品定位

面向零基础准创业者，半对话渐进式引导，双轨并行学习模式，自动生成分层总结报告。

#### 核心交互规则（半对话 Agent 强制逻辑）

1. 分步提问，禁止一次性推送海量信息。
2. 用户选择行业后，主动提供两种模式切换入口：极速入门（核心关注点）、系统深耕（全链路拆解）。
3. 任意模式可随时双向跳转：链路节点一键查看对应核心痛点，核心关注点一键追溯对应产业链路。
4. 每完成单个链路节点自动生成节点小结；用户可手动触发阶段总结、完整行业报告。

#### 双轨指引体系开发细则

**3.3.1 轨道 A：行业核心关注点（极速入门）固定 8 大模块输出模板**

后台配置固定字段，AI 不可自由删减，仅填充对应行业数据：

1. **行业核心盈利点位**：高利润链路、套利潜规则、新手低门槛赛道。
2. **行业亏损踩坑点**：高频亏损节点、新手误区、合规红线、商业骗局。
3. **核心量化指标 Top10**：指标计算公式、优秀/及格/不及格阈值、上下游影响。
4. **现金流与账期规则**：通用结算模式、坏账高发场景、资金积压节点。
5. **准入门槛**：资金、人脉、资质、技术门槛。
6. **行业周期**：淡旺季、涨价/下跌周期、备货/清仓节点。
7. **隐形行规**：无书面合同的通用合作惯例。
8. **最新机遇 & 风险**：联动情报引擎拉取近 90 天权威动态情报。

**3.3.2 轨道 B：全链路系统学习（七大链路逐节点输出模板）**

每个链路节点固定 6 段输出结构，系统强制填充：

1. 节点基础流程简述
2. 该节点专属核心关注点（盈利 + 风险）
3. 节点关键量化指标
4. 节点隐形行规
5. 上下游联动传导影响
6. 节点自动精简小结

**3.3.3 区间萃取功能开发逻辑**

支持用户输入区间指令（如生产-品控、渠道-回款），系统执行流程：

1. 解析用户指定链路节点 ID 集合。
2. 检索该区间内静态知识库内容 + 匹配区间关联情报。
3. 合并去重、按机遇/风险分类排序。
4. 生成区间专属浓缩总结，挂载对应数据源链接。

#### 三级总结生成开发规范

1. **一级·单节点即时总结**：固定 5 维度精简输出（价值、风险、指标、行规、联动影响）。
2. **二级·阶段性总结**：汇总用户已学习全部节点，合并共性问题、关联逻辑。
3. **三级·全行业完整报告**：固定 8 大章节，自动嵌入实时情报板块《当前行业外部机遇与风险动态》。

#### 前端页面固定结构

1. **顶部栏**：当前行业名称、当前学习模式切换按钮。
2. **中间主体**：Agent 对话窗口，渐进式分块输出内容。
3. **右侧悬浮快捷指令按钮（固定不可删减）：**
   - 切换核心关注点模式
   - 切换全链路学习
   - 查看下一节点
   - 萃取当前节点干货
   - 总结对话
   - 生成完整行业报告
   - 追溯重点对应链路
4. **底部**：历史对话记录、历史报告存档入口。

### 2.4 模块2：经营诊断Agent 完整开发规范

#### 产品定位

面向已在营创业者，半对话分步采集用户一手经营数据，作为最高权重推理依据，多维度诊断，输出分级优先级整改方案。

#### 用户一手经营数据采集开发细则

**4.2.1 分步采集字段（一问一答，不一次性弹窗）**

1. **基础地域**：所在省/市/区县（用于过滤本地专属情报、本地人工扫盲信息）。
2. **经营基础**：经营时长、线上/线下经营模式、门店规模。
3. **经营财务**：月度营收、综合成本、净利润、库存积压金额。
4. **渠道现状**：获客渠道、渠道投入成本、转化率、复购。
5. **供应链现状**：供应商数量、拿货成本、账期、断供情况。
6. **用户自主描述**：当前最头疼 3 项经营问题。
7. **人员、合规、库存损耗补充信息**。

**4.2.2 用户数据存储强制约束**

1. 前端弹窗提示禁止上传身份证、客户手机号、完整供应商私人联系方式。
2. 后端 NLP 自动识别文本内手机号、身份证、详细地址，自动脱敏打码入库。
3. 数据库加密存储，仅当前登录账号可读，超级管理员无法查看明文。
4. 数据生命周期：普通对话 90 天自动销毁；付费用户报告可手动导出，原始会话到期删除，仅留存脱敏摘要。
5. 用户登录弹窗授权二选一：① 匿名数据用于产品优化训练；② 拒绝，数据仅本次会话使用，到期彻底删除。

#### 八大诊断维度开发逻辑（固定诊断顺序）

1. **地域 & 人文市场诊断**：匹配本地情报、本地消费习惯、行业饱和度、本地政策。
2. **供应链诊断**：对比本地原料/物流成本均值，定位成本偏高节点。
3. **仓储库存诊断**：库存周转、呆滞库存、损耗率对标行业基准。
4. **渠道流量诊断**：渠道投产比、流量枯竭、平台规则变动影响。
5. **同行竞争诊断**：本地头部/腰部商家打法、价格内卷、获客手段。
6. **内部全链路对标诊断**：将用户经营数据对标行业七链路标准，定位亏损节点。
7. **现金流 & 账期风险诊断**：坏账、账期过长、资金积压风险。
8. **外部情报归因诊断**：自动匹配本地政策、原料涨价、平台新规等外部诱因。

#### 问题分级与优先级算法开发

**4.4.1 四级分级标准**

1. **致命级**：不整改持续大额亏损、合规处罚风险、现金流断裂。
2. **高优级**：1-2 周落地可显著提升利润。
3. **中优级**：中长期优化项目。
4. **观察级**：波动较小，无需调整。

**4.4.2 输出整改方案规范**

每条整改内容包含：问题成因、影响利润比例、落地执行步骤、短期/长期优化目标、配套本地情报依据、风险提示。

#### 双 Agent 互通联动开发逻辑

1. 诊断过程发现用户链路短板，一键跳转入行 Agent 对应节点学习。
2. 用户完成行业学习后，一键进入诊断模式，使用行业标准自查经营问题。
3. 两套 Agent 共享同一套行业、情报、地域数据库，数据互通。

#### 诊断报告专属板块

固定新增《区域市场外部环境研判》板块，全部基于实时抓取情报、本地人工采集信息生成，区分全国通用规则与本地特殊规则。

### 2.5 模块3：服务端情报感知引擎

#### 七层分层架构（由外至内，串行执行，缺一不可）

采集调度层 → 清洗标准化层 → NLP 语义关联层 → 机遇风险研判层 → 存储同步层 → 后台管理告警层 → API 输出层。

#### 第一层：多源采集调度层开发规范

**5.2.1 数据源分类与抓取权限约束**

| 数据源类别 | 权重等级 | 抓取约束 |
|---|---|---|
| 政务类（发改委、工信部、市监局、海关等） | S 级最高权重 | 无抓取限制 |
| 权威行业机构（行业协会、官方数据平台） | A 级 | 无抓取限制 |
| 商业付费平台 | — | 禁止直接爬虫，仅官方 API 合作采购，仅抓取公开免费摘要 |
| 自媒体/论坛 | C/D 级 | 单次截取正文 ≤ 200 字，遵循合理引用，禁止完整转载 |
| 封禁站点、营销垃圾站点 | 黑名单 | 录入黑名单，永久不抓取 |

**5.2.2 定时抓取任务配置（后台可视化配置）**

| 数据类型 | 抓取频率 |
|---|---|
| 政策类 | 每日 0 点、12 点两轮全量扫描 |
| 大宗商品、物流运价 | 每 4 小时增量抓取 |
| 行业资讯、消费热度 | 每日 8 点、18 点抓取 |
| 重大事件触发机制 | 识别 4 级风险情报，自动提升抓取频率至 1 小时/次，持续跟踪 7 天 |

**5.2.3 爬虫合规强制配置**

1. 抓取间隔最低 3 秒，单站点并发 ≤ 2。
2. 自动校验 `robots.txt`，禁止抓取禁止目录。
3. 代理池轮换限速，禁止高频轰炸站点服务器。
4. 抓取失败自动重试 3 次，连续失败标记站点异常，推送运维告警。

#### 第二层：原始数据清洗标准化层

**5.3.1 清洗流程开发步骤**

1. **指纹去重**：URL 指纹 + 文本相似度双重去重。
2. **垃圾过滤**：广告、营销软文、无关内容直接丢弃。
3. **正文提取**：剥离导航、弹窗、广告块，仅保留标题 + 正文。
4. **统一格式化**：时间戳、来源名称、地域标签、原文 URL 标准化。
5. **数值抽取**：自动提取涨幅、价格、补贴、产能、税率等量化数值存入结构化字段。

**5.3.2 基础情报结构化字段**

情报 ID、行业 ID 数组、子行业、来源类型、来源名称、原文 URL、发布时间、抓取时间、地域标签、原始标题、正文摘要、量化数值集合、原始置信度、来源权重等级。

#### 第三层：NLP 语义解析与链路关联层

**5.4.1 三步识别逻辑**

1. **行业实体识别**，绑定后台行业分类 ID。
2. **链路节点匹配**，绑定七大链路节点 ID，支持单情报关联多区间。
3. **事件标签分类**：政策扶持、监管收紧、原料涨价、产能扩张、渠道变更等固定标签池。

**5.4.2 新增关联字段**

绑定行业 ID 列表、绑定链路节点 ID 列表、事件类型、地域范围、量化变动值、影响周期（短期 < 3 月 / 中期 3-12 月 / 长期 > 1 年）。

#### 第四层：机遇 & 风险智能研判模型层

**5.5.1 研判规则（规则引擎 + 小模型双校验，可后台可视化配置阈值）**

| 类别 | 判定条件 |
|---|---|
| **机遇判定** | 税收减免、补贴、原料降价、流量倾斜、产业招商 |
| **风险判定** | 限产、严查、原料暴涨、渠道扣点提升、行业饱和、安全事故 |

**5.5.2 四级严重度自动打分**

1 级观察、2 级中性、3 级重要、4 级致命。

**5.5.3 全链路传导推演自动生成**

示例：原料涨价 20% → 生产成本上升 → 终端售价上浮 → 渠道利润压缩 → 回款周期拉长，文本自动存入情报字段，Agent 直接调用展示。

#### 第五层：存储与公共知识库同步层

1. **双存储**：MySQL 结构化数据、向量库存储情报向量用于语义检索。
2. **同步机制**：每小时批量将新增情报同步至公共行业知识库，挂载至对应链路节点。
3. **生命周期管理**：短期情报 3 个月标记过期，前端弱化展示；中长期政策长期置顶；超 1 年情报归档冷存储。

#### 第六层：后台配置、人工复核、告警模块

**5.7.1 后台核心功能开发**

情报总览看板、情报人工复核、行业抓取关键词管理、数据源启停配置、研判规则阈值调整、地域筛选、历史情报检索。

**5.7.2 4 级致命情报告警机制**

后台弹窗、企业微信/短信推送管理员、用户登录首页置顶提醒；告警内容包含事件摘要、传导推演、简易应对建议。

**5.7.3 后台三级权限**

超级管理员（全配置）、运营管理员（仅复核查看）、只读账号（仅检索），所有操作日志留存 6 个月。

#### 第七层：对外标准化 API（供双 Agent 调用）

1. **基础情报查询 API**：入参行业 ID、地域、链路、机遇/风险、等级、时间。
2. **链路批量情报 API**：指定行业 + 节点，返回近 90 天情报。
3. **重大置顶情报 API**：返回 4 级致命情报。
4. **语义检索 API**：用户提问文本匹配向量库情报。
5. **诊断专属联动 API**：入参行业、城市、经营问题，匹配本地外部风险情报。

**统一返回字段**：标题、来源、时间、地域、机遇/风险标识、严重等级、影响链路、量化变动、传导推演、简易应对建议、原文链接。

### 2.6 模块4：四大信息感知盲区补全系统

#### 四类盲区定义与对应四层补盲体系

四层补盲：技术自动补盲、真人本地化扫盲、付费专项情报、法律红线避让。

**6.1.1 区域性信息盲区**

解决方案开发点：

1. 省市县三级地域抓取矩阵，全国/省/市/区县多层数据源。
2. 地域子知识库隔离机制，本地信息仅优先展示对应城市用户，不覆盖全国通用规则。
3. 人工扫盲后台录入模块：本地市场走访情报录入入口，标注采集城市、采集人、置信度。
4. 付费情报录入模块：行业资深从业者供稿，标记付费内幕标签，仅付费会员可见。

**6.1.2 即时信息盲区**

解决方案开发点：

1. 事件触发动态升频抓取。
2. 短时波动情报单独标签，诊断时提示"短期波动，不作为长期经营依据"。
3. 人工即时上报通道：运营实时录入当日突发市场变动。

**6.1.3 真实性不确定信息盲区**

解决方案开发点：五级信源权重打分、多源交叉核验、孤证低权重信息不参与风险研判、强制标注存疑话术。

**6.1.4 政府封锁/合规屏蔽信息盲区**

强制开发约束：

1. 无任何抓取、快照回溯、暗网采集逻辑。
2. 数据库无封禁信息存储字段。
3. Agent 遇到该类信息空白固定输出合规盲区话术，禁止 AI 猜测、编造内容。

#### 人工扫盲系统完整开发模块

1. **情报录入表单**：城市、行业、链路区间、内容、采集时间、采集人员、置信度标签。
2. **双人复核流程**：录入员提交 → 审核员校验入库。
3. **前端展示标签**：【人工实地采集｜非网络公开信息】。
4. **数据隔离**：人工情报与爬虫情报分表存储，统一接口对外输出。

#### 付费情报增值模块开发

1. **权限控制**：免费用户不可查看付费情报，会员解锁。
2. **情报脱敏机制**：去除企业名称、个人隐私、具体底价。
3. **专项定制情报工单**：用户可发起指定城市/行业情报采集申请，运营接单后补充入库。

### 2.7 模块5：恶意虚假信息识别与拦截全链路

#### 四类恶意信息识别特征库内置

1. **极端情绪煽动类**：全面崩盘、一刀切、暴涨翻倍、闭眼暴富等关键词库。
2. **批量水军搬运**：短时间 10 个以上低权重站点完全相同文案。
3. **旧闻翻新**：时间戳比对，往年新闻修改日期冒充新资讯。
4. **同行恶意抹黑**：针对性夸大行业负面、捏造平台新规、虚假倒闭潮。

#### 五层拦截串行开发流程（情报入库前置强制执行）

1. **抓取源头黑名单拦截**：恶意自媒体、营销站点直接丢弃数据。
2. **NLP 恶意语义分类模型**：标记正常资讯/普通误传/恶意恐慌造谣/虚假红利/同行抹黑。
3. **多源交叉核验规则**：S/A 级 1 条可采信，B/C/D 级需 ≥ 5 条不同信源佐证，单源极端消息直接作废。
4. **权重降级处置**：标记恶意谣言情报取消风险/机遇标签，不参与诊断归因，不首页推送。
5. **前端公示拦截**：输出标准化谣言提示话术，告知用户信息已过滤。

#### 复核台账与模型自迭代开发

1. 数据库新建虚假信息复核台账，存储所有疑似造谣情报。
2. 后台每日复核页面，运营标记真假，确认谣言自动加入关键词/域名黑名单。
3. 复核结果数据集自动回流训练 NLP 模型，持续提升识别准确率。

#### 情报库新增谣言相关字段

| 字段名 | 类型 | 说明 |
|---|---|---|
| `is_malicious_rumor` | tinyint | 是否恶意谣言 |
| `rumor_type` | varchar | 谣言类型 |
| `truth_check_result` | varchar | 真伪核验结果 |
| `source_confidence_final` | float | 最终信源置信度 |
| `forbid_strategy_level` | int | 拦截策略等级 |

### 2.8 模块6：新旧信息差异冲突智能甄别处置

#### 四大冲突分类

1. 真实行业迭代更新
2. 短期市场波动
3. 区域性特例
4. 恶意虚假冲突

#### 七层串行校验算法（情报研判前强制执行）

1. **时间差校验**：间隔 > 6 个月倾向迭代，< 7 天倾向波动/谣言。
2. **信源权重碾压**：低权重新情报不可覆盖高权重历史知识库。
3. **多源一致性校验**：权威多源一致才判定有效变更。
4. **行业逻辑基线校验**：违背行业常识判定可疑冲突。
5. **地域隔离校验**：局部地域信息不修改全国通用知识库。
6. **临时/永久标签区分**：废止/新规为永久变更，临时/阶段性为短期波动。
7. **历史趋势拟合**：脱离长期趋势跳变数据标记可疑，人工复核。

#### 四类冲突标准化处置逻辑

1. **权威永久行业迭代**：自动更新对应链路知识库，旧版本归档留存可回溯。
2. **短期市场波动**：仅作为动态情报展示，不修改底层静态知识库。
3. **区域性特例**：仅写入地域子库，全国通用数据保持不变。
4. **虚假造谣冲突**：直接拦截，不入库、不参与推理、拉黑来源。

#### 配套台账与前端话术

1. 新建新旧信息冲突台账，记录所有矛盾情报、处置结果、复核人。
2. 前端配套标准化话术：行业迭代更新提示、短期波动提示、本地特例提示、虚假传言过滤提示。

### 3.3 索引与性能设计

1. **主键索引**：所有表均以自增 `bigint` 或 `varchar(64)` UUID 作为主键。
2. **唯一索引**：`raw_crawled_intelligence.url` 建立唯一索引；`industry_knowledge_base.industry_name` 建立唯一索引。
3. **普通索引**：
   - `user_session_data.user_id` 索引用户会话查询。
   - `raw_crawled_intelligence.crawled_at` 索引按时间查询。
   - `raw_crawled_intelligence.text_fingerprint` 索引指纹去重。
   - `structured_intelligence.raw_intel_id` 唯一索引关联查询。
   - `crawl_keyword_config.industry_id` 索引关键词配置查询。
   - `fake_info_review_ticket.intel_id` 索引台账查询。
   - `info_conflict_ticket.new_intel_id` 和 `old_knowledge_id` 索引冲突台账查询。
   - `manual_survey_intel.industry_id` 索引人工情报检索。
4. **复合索引建议**：
   - `structured_intelligence` 建立 `(industry_ids, severity_level, impact_cycle)` 复合索引用于多维情报检索。
   - `raw_crawled_intelligence` 建立 `(source_type, crawled_at)` 复合索引用于按来源+时间统计。
5. **性能设计要点**：
   - 热数据（近 90 天情报）常驻 MySQL，超 1 年数据自动迁移至冷存储对象存储。
   - 向量数据存入独立向量数据库（如 Milvus/Pinecone），不占用 MySQL 空间。
   - 用户敏感数据字段 AES 加密存储，禁止明文索引。
   - 付费情报与免费情报物理分表/分库（`intel_vip` / `intel_public`）。
   - 定期垃圾数据清理：过期死信、废弃缓存、冗余快照、测试脏数据自动治理。

## 第四部分：API 规范

### 4.1 API 设计原则

1. **统一网关前置**：所有请求先经过 API 网关，完成鉴权、限流、日志埋点后转发至后端服务。
2. **统一入参出参**：公共入参必须包含 `access_token`、`user_id`、`industry_id`、`city_code`、`mode`；公共返回必须包含 `code`、`msg`、`data`、`warning_notes`。
3. **强制数据隔离**：所有查询接口强制携带用户行业、地域、会员等级过滤条件，自动隔离数据。
4. **乐观锁写入**：写入接口加乐观锁，防止并发覆盖。
5. **异常统一处理**：统一异常捕获、分级错误码、完整异常日志上报监控。
6. **鉴权与限流**：所有接口必须鉴权，敏感接口限流防刷，付费接口校验会员权限。

### 5.1 前端话术模板（8种分场景固定话术）

所有 AI 输出强制前置统一免责头部，然后根据场景类型拼接对应话术。

#### 统一免责头部

> 本内容仅基于公开资讯、行业数据推演，不构成官方经营、投资决策指导，大额投入请线下咨询属地监管、专业财税/商业顾问。

#### 8 种分场景话术模板

**话术 1：区域信息不足**
> 提示：当前 [地域名称] 区域的 [行业名称] 本地信息覆盖尚不完整，部分数据来源于周边区域或全国通用数据，建议结合本地实际经营情况综合判断。

**话术 2：即时信息滞后**
> 提示：本条信息抓取时间为 [抓取时间]，与当前可能存在一定时差。行业动态变化较快，请关注最新信息。

**话术 3：信息存疑**
> 提示：本条信息来源单一、置信度较低，暂无法通过交叉验证确认其真实性，建议多方核实后再做决策。

**话术 4：合规封锁盲区**
> 提示：根据合规要求，涉及政府封锁、下架等相关信息本平台不采集、不推演、不猜测，建议关注官方公告。

**话术 5：恶意造谣过滤**
> 提示：系统已识别并过滤疑似恶意造谣信息，当前内容未采用该数据，请以权威渠道发布信息为准。

**话术 6：行业规则迭代**
> 提示：检测到 [行业名称] 相关规则已发生更新（[更新时间]），旧规则仅供参考，建议按新规调整经营策略。详细变更内容可查看溯源链接。

**话术 7：短期市场波动**
> 提示：本条情报标记为短期市场波动（影响周期 < 3 月），请结合长期趋势综合判断，不建议以此作为长期经营决策依据。

**话术 8：本地地域特例**
> 提示：本条信息为 [城市名称] 地域特例情况，不适用于全国通用场景，跨地域经营时请注意区分。

## 第六部分：运维与安全

### 6.1 运维架构

| 层级 | 组件 | 说明 |
|---|---|---|
| **缓存层** | Redis 多级缓存 | 四层缓存架构：爬虫页面缓存、API 响应缓存、知识库全局缓存、局部维度缓存 |
| **任务调度** | XXL-JOB 分布式 | 定时抓取任务、数据同步任务、数据销毁任务、巡检任务调度 |
| **日志收集** | ELK Stack | 全链路日志统一收集、检索、可视化 |
| **监控度量** | Prometheus + Grafana | CPU/内存/数据库负载/爬虫成功率/API 调用量等指标 |
| **备份恢复** | 异地备份 | MySQL 每日全量异地备份 + 增量备份，向量库定时快照，冷存储自动归档迁移 |
| **环境隔离** | 四套物理环境 | 开发/测试/预发/生产独立资源，灰度分批发布流程 |
| **容器编排** | Docker + K8s（可选） | 服务容器化部署，弹性伸缩，故障自愈 |

### 6.2 安全规范

| 安全类别 | 规范内容 |
|---|---|
| **数据安全** | 用户敏感数据 AES 加密存储；手机号、身份证等 PII 自动脱敏；禁止明文持久化 |
| **传输安全** | 全站 HTTPS；API 接口统一网关前置鉴权与限流 |
| **权限安全** | RBAC 双层权限（功能权限 + 数据权限）；四层多租户数据隔离；全接口前置权限校验 |
| **防攻击** | 接口限流防刷；防 SQL 注入；定期渗透测试；服务器端口最小化开放 |
| **内容安全** | 输入/输出双层敏感词过滤；舆情风控审计；灰色内容一键隐藏 |
| **审计安全** | 后台操作分级审计，操作日志留存 ≥ 6 个月；全链路流水号可追溯 |
| **容灾安全** | 异地每日备份，本地备份校验，单库故障恢复预案，一键回滚 |

### 6.3 监控告警

#### 三级分级告警

| 告警级别 | 触发条件 | 推送渠道 | 响应时间 |
|---|---|---|---|
| **P0 紧急（红色）** | 服务瘫痪、核心数据库不可用、大模型 API 完全不可用 | 企业微信 + 短信 + 电话 | ≤ 15 分钟 |
| **P1 重要（橙色）** | 爬虫大面积失败、API 响应超时率 > 10%、单模块故障 | 企业微信 + 短信 | ≤ 30 分钟 |
| **P2 一般（黄色）** | 单站点爬虫失败、接口调用量异常波动、缓存命中率下降 | 企业微信 | ≤ 2 小时 |

#### 监控指标清单

| 指标类别 | 具体指标 |
|---|---|
| **服务健康** | CPU 使用率、内存使用率、磁盘 IO、网络流量 |
| **数据库** | 连接数、慢查询数、主从延迟、负载 QPS |
| **爬虫** | 抓取成功率、增量抓取占比、代理池可用率、队列堆积数 |
| **API** | 调用量、成功率、平均响应时间、P99 延迟 |
| **AI 推理** | 推理调用量、平均推理时间、自检通过率、降级触发次数 |
| **缓存** | 命中率、缓存大小、过期淘汰率 |
| **业务** | 日活跃用户数、会话数、报告生成数、付费转化率 |

#### 告警自动处理

- 爬虫故障 → 自动切换备用数据源 / 缓存兜底
- API 故障 → 自动切换多厂商冗余通道
- 数据库故障 → 自动切备库 / 异地备份恢复
- 大模型故障 → 自动切换备选模型 / 本地轻量模型兜底 / 限流排队提示
