# BizSage V3 全域商业化封顶终版里程碑

## V3 范围

V3 是全域商业化封顶终版，将 V2 生产灰度系统升级为完整商业化产品，补齐商业变现、动态数据治理、完整安全、全终端交付、可审计、运营报表和 99.9% SLA 能力。

V3 受 `docs/zh-CN/` 下治理文档及 `docs/en/` 英文对应文档约束。V3 实现 `docs/zh-CN/milestones/product-milestones-zh-CN.md` 中定义的 V3 范围。

系统必须验证：

- 从会员购买到权益、报告交付和运营的商业闭环完整；
- 动态信源权重、数据血缘、自动清理和热/温/冷生命周期可运行；
- 付费情报和租户数据完成物理与逻辑隔离；
- PC 与 H5 终端可用并具备友好降级；
- 安全、合规、审计和运营资产达到商业上线准备状态。

## 不在范围内

- 单独 V4 阶段；源路线图到 V3 结束。
- 未批准的生态市场或第三方插件平台。
- 实施商业上线范围外的无关功能。
- 在缺少度量证据和运维资产时宣称 99.9% 生产 SLA。

## 里程碑计划

### M0 V2 灰度退出与商业范围锁定

- 复核 V2 灰度结果和故障记录。
- 批准定价、会员分层、权益模型、报告组合、合规假设和上线清单。
- 锁定 V3 安全、可靠性、数据隔离、成本和交付目标。

验收：只有在 V2 退出标准和商业假设均获批准后，V3 才能开始。

### M1 动态数据治理

- 基于复核通过率、冲突频次、新鲜度、基线一致性和合规等级实现实时动态信源权重。
- 实现从采集、清洗、治理、存储、检索、推理到报告输出的完整数据血缘。
- 实现过期、死信、冗余快照和测试脏数据清理。
- 实现热/温/冷存储迁移策略。

验收：每条商业情报都可逆向追溯、动态加权并进行生命周期管理。

### M2 完整多租户与付费情报隔离

- 完成用户私有、地域、行业、权益四层多租户物理隔离。
- 增加付费情报独立分库和导出限制。
- 所有商业 API 增加垂直和水平越权校验。
- 增加敏感数据访问管理员审计轨迹。

验收：权限测试证明跨租户、跨地域、跨行业和免费访问付费均被阻断。

### M3 会员、订单、权益与商业运营

- 增加会员分层、套餐、订单记录、权益开通、到期和降级行为。
- 增加付费报告下载和权益校验。
- 增加会员生命周期和留存运营字段。
- 完成用户投稿激励运营：复核、奖励、防滥用和审计。

验收：购买到权益、权益到内容、到期和降级流程均可测试并留痕。

### M4 完整报告组合

- 增加五类报告：入行学习报告、市场调研报告、经营诊断报告、专题风险报告和周期复盘报告。
- 标准化报告章节、证据、置信、时效、免责声明和导出格式。
- 增加报告历史、下载和权限校验。

验收：每类报告都可带证据生成，并且只有授权用户可下载。

### M5 双 Agent 完整个性化

- 完成行业、地域、规模、会员、偏好、痛点和历史行为等精细用户画像标签。
- 动态信源权重参与推理。
- 增加个性化建议和后续学习/诊断动作。
- 完成所有 Agent 输出安全与合规审计闭环。

验收：商业场景输出具备个性化、可溯源、地域适配和合规约束。

### M6 安全、合规与审计后台

- 增加防爬和付费内容防批量导出。
- 增加输入和输出风控审计。
- 增加完整管理员操作审计后台。
- 准备适用场景下的等保就绪材料。
- 增加审计日志和内容血缘的法务举证导出。

验收：安全审查覆盖敏感 API、付费内容、管理员操作、审计日志和故障证据。

### M7 终端交付与运营报表

- 增加完整 H5 移动端适配和弱网兜底。
- 增加会员中心、历史对话、报告下载和订阅/权益视图。
- 增加信源成本、情报产出、模型成本、使用量、转化和故障的月度运营报表导出。
- 增加运营和客服标准化交付资产。

验收：PC 和 H5 用户可完成商业流程，运营可导出月度报表。

### M8 SLA、压测、灾备与上线就绪

- 执行压测并记录容量、延迟和瓶颈。
- 执行灾备和回滚演练。
- 验证 SLA 大屏和故障时长统计。
- 补齐架构文档、部署脚本、运维手册、故障预案、压测报告和 API 文档。
- 完成上线合规清单和签署。

验收：V3 只有在商业上线证据已记录，或每个例外都有批准的修复任务和负责人时才能退出。

## 验证命令

- API：在 `services/api` 运行 `mvn test`。
- Collector：在 `services/collector` 运行 `python -m pytest`。
- AI worker：在 `services/ai-worker` 运行 `python -m pytest`。
- Web：在 `apps/web` 运行 `npm test` 和 `npm run build`。
- 文档：移动或修改文档后运行 Markdown 双语配对检查。
- 商业就绪：在 V3 验证文档中记录压测、灾备、安全和上线合规证据。

如果当前环境无法运行长时间压测、SLA、灾备或安全验证，必须记录尝试命令、原因、风险和修复计划。
