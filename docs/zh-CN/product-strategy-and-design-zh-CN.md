# 第一部分：市场与技术趋势

## 1.1 2026年Agent开发关键技术全景

当前行业主流 Agent 已经从简单对话 + 基础 RAG 演进到运行时工程、多智能体协同、结构化业务推理、全链路风控治理、记忆分层、符号-神经混合校验体系。下面分十大核心关键技术，逐一说明技术定义、行业价值、本项目已落地/可复用/待补充情况，完全贴合「入行 Agent + 经营诊断 Agent + 情报感知引擎」完整系统。

### 1.1.1 Agentic RAG（智能检索增强生成，2026 落地第一核心技术）

**技术定义**

区别于传统静态 RAG，具备自主检索规划、多源证据交叉校验、分层检索、证据溯源、可信度打分、动态过滤无效信息的检索架构，解决大模型幻觉、信息过时、虚假信息、信息盲区四大痛点。

**核心细分能力**

1. 分层检索：静态知识库、爬虫情报向量库、人工扫盲情报、付费圈层情报分库检索
2. 多源交叉核验：S/A/B/C/D 五级信源权重自动加权
3. 检索前置风控：谣言过滤、新旧信息冲突校验后再送入模型
4. 证据绑定：每一段 AI 输出绑定对应情报 ID、原文链接，实现溯源
5. 动态上下文压缩（Context Engineering）：只把有效行业数据注入模型上下文，避免超长文本溢出、成本飙升

**本项目匹配情况**

已完整落地：
1. 双存储架构：MySQL 结构化情报 + 向量数据库语义检索
2. 五级信源权重、多源交叉核验机制（恶意虚假信息拦截模块）
3. 新旧信息冲突甄别算法，检索前自动过滤过时/虚假情报
4. 所有 AI 输出强制挂载情报来源、原文链接、置信度标注
5. 区分 6 维信息权重优先级：用户一手经营数据 > 人工情报 > 权威抓取情报 > 行业静态库
6. 情报分层检索：按行业、城市、链路节点精准过滤本地信息，解决区域性信息盲区

可深化复用（后续迭代优化点）：
1. 引入检索重排（Rerank）模型，提升情报匹配精准度
2. 增加检索反思机制：Agent 回答缺信息时，自动触发情报引擎二次定向抓取
3. 上下文动态裁剪，自动压缩历史对话冗余内容，降低 LLM 调用成本

### 1.1.2 Agent Runtime 智能体运行时工程（2026 生产级必备底座）

**技术定义**

不再是零散 Prompt + 函数调用，而是一套可观测、可治理、状态持久、容错重试、模块化插拔的统一运行时底座，统一管理记忆、工具调用、任务编排、风控拦截、日志审计、模型路由。核心模块：会话状态机、记忆管理器、工具网关、风控沙箱、可观测追踪、多模型负载均衡。

**本项目匹配情况**

已有底层雏形，大部分能力已落地：
1. 会话生命周期管理：用户对话 90 天自动销毁、加密存储、会话状态持久化
2. 统一 API 网关，所有 Agent、情报、后台工具统一路由
3. 完整全链路日志审计：抓取日志、AI 推理日志、情报复核日志、告警日志留存 6 个月
4. 任务重试容错：爬虫抓取失败 3 次重试、AI 调用失败自动切换备用模型
5. 三级权限隔离、操作留痕、后台风控配置面板
6. 多模型主备切换机制，解决第三方 API 依赖风险

待标准化补齐（下一阶段开发）：
1. 标准化状态机编排（LangGraph 风格），把入行/诊断完整流程做成可视化节点
2. 统一 Agent 追踪 Tracing，每条 AI 推理链路可完整回放溯源
3. 独立执行沙箱，隔离情报抓取、NLP 推理、用户数据处理流程，安全隔离

### 1.1.3 分层记忆系统（短期对话记忆 + 长期行业记忆 + 用户私有记忆）

**技术定义**

2026 主流三层记忆架构，替代单一对话缓存：
1. 短期记忆：当前会话上下文、用户本轮提问、临时情报结果
2. 长期公共记忆：行业知识库、历史时序情报、历年政策/成本数据（向量持久存储）
3. 用户私有记忆：用户经营数据、历史诊断报告、本地专属偏好，加密隔离存储，仅本人可见

配套能力：记忆压缩、记忆检索、记忆过期自动清理、记忆权限隔离。

**本项目匹配情况**

完整落地三层记忆架构：
1. 短期记忆：双 Agent 会话上下文、分步问诊缓存
2. 长期公共记忆：行业静态知识库、时序情报归档库、人工扫盲情报持久存储
3. 用户私有加密记忆：经营数据 AES 加密、脱敏、90 天自动销毁、授权双选项
4. 生命周期管理：短期情报 3 个月过期弱化展示，超 1 年情报归档冷存储
5. 记忆隔离：本地情报、全国通用知识库、付费情报分库隔离，权限可控

### 1.1.4 多智能体协同编排（Multi-Agent，分层角色 Agent 分工）

**技术定义**

拆解复杂业务为多个专业子智能体，分工协作完成完整任务，典型角色：
1. Planner 规划 Agent：拆解用户复杂经营问题，规划检索、诊断、报告步骤
2. Knowledge 检索 Agent：专职调取知识库、全网情报、人工本地信息
3. Risk 风控 Agent：专职拦截虚假信息、新旧冲突、违规内容、幻觉
4. Diagnosis 诊断 Agent：经营数据对标、短板分级、整改方案生成
5. Report 报告 Agent：标准化总结、行业报告导出、格式统一排版

主流框架：LangGraph、AutoGen，支持分支、循环、重试、子任务动态生成。

**本项目匹配情况**

业务逻辑已实现多角色分工（自研编排，可迁移标准化框架）：
1. 天然拆分五大职能模块，对应多 Agent 角色：
   - 规划层：入行引导分步逻辑、诊断八维问诊流程
   - 检索层：情报引擎统一检索服务
   - 风控层：谣言拦截、新旧冲突校验双风控子模块
   - 诊断推理层：经营数据加权研判、风险分级
   - 输出层：三级总结、标准化报告生成
2. 双 Agent 互通跳转：入行 Agent 与诊断 Agent 双向联动，共享底层数据
3. 条件分支逻辑：区分免费/付费用户、区分全国/本地信息、区分短期波动/长期行业迭代

可优化升级：采用 LangGraph 标准化图式编排，将现有业务流程改为可视化可配置节点，降低迭代改造成本。

### 1.1.5 符号-神经混合推理架构（规则引擎 + 大模型双校验，垂直行业刚需）

**技术定义**

解决纯大模型幻觉、结论不可解释问题：
1. 符号层（规则引擎）：固定行业硬规则、风险分级阈值、抓取合规约束、数据校验标准、风控拦截逻辑（可后台可视化配置）
2. 神经层（LLM）：自然语言理解、语义匹配、文本生成、传导推演
3. 双向校验：模型输出必须过规则引擎校验，规则异常强制拦截、人工复核

核心场景：四级风险研判、虚假信息判定、新旧冲突校验全部属于符号规则层。

**本项目匹配情况**

深度落地，产品核心壁垒：
1. 全系统大量可视化可配置规则引擎：
   - 情报抓取调度规则、抓取合规约束
   - 五级信源权重、交叉核验硬规则
   - 机遇/风险四级分级阈值、传导推演固定逻辑
   - 恶意谣言识别关键词库、冲突七层校验规则
   - 法律合规强制拦截规则（封锁信息不采集、隐私脱敏）
2. 双层校验机制：NLP 语义识别 + 业务规则引擎双重校验，大幅降低幻觉
3. 所有经营诊断量化指标由规则计算，AI 仅做解读，数值结果不依赖大模型生成，杜绝数据造假

### 1.1.6 工具调用标准化（Skill 工具集，业务 API 封装）

**技术定义**

把系统底层能力封装为标准化可调用 Skill 工具，Agent 自主按需调用，统一入参、返回格式、鉴权、限流，包含：数据库查询、情报检索、爬虫调度、报告生成、用户数据读取、人工情报查询、风控校验等能力。

**本项目匹配情况**

已完整标准化 API 工具集：
1. 对外统一标准化 API 分组，覆盖情报查询、诊断、入行、报告、后台管理
2. 所有底层能力封装独立服务：爬虫调度服务、知识库服务、风控服务、人工情报服务
3. 工具调用统一鉴权 access_token、统一返回 code/msg/data/warning_notes
4. 工具限流、失败重试、调用日志全留存

### 1.1.7 Context Engineering 上下文工程（2026 解决幻觉核心技术）

**技术定义**

不再依靠单一 Prompt 约束，系统化管理每一轮送入大模型的上下文：动态筛选有效数据、冗余信息压缩、风险标注前置、合规免责强制注入、权重信息优先置顶、无效情报过滤剔除。

**本项目匹配情况**

已落地全套上下文管控机制：
1. 六维信息权重强制排序，高优先级数据优先注入上下文
2. 存疑/虚假情报自动过滤，不送入 LLM 推理
3. 所有输出强制前置统一免责话术、信息盲区标注、谣言过滤提示
4. 本地地域情报优先展示，全国通用信息后置
5. 短期波动情报自动附加提示文本，区分长期行业规则

### 1.1.8 GraphRAG 知识图谱检索（产业链结构化图谱）

**技术定义**

将行业七链路、上下游供应商、政策影响、成本传导关系构建知识图谱，实现关联因果检索，不只是文本相似度匹配，可自动推导原料涨价→生产→渠道→销售全链路传导逻辑。

**本项目匹配情况**

已有图谱逻辑雏形，待完善图存储：
1. 底层固定七大产业链路关联结构，情报自动绑定上下游链路节点
2. 自动生成全链路传导推演文本（原料涨价连锁影响）
3. 情报可按链路区间检索（区间萃取功能）

待落地优化：新增图数据库存储产业链关联关系，实现多跳因果检索，强化经营诊断归因能力。

### 1.1.9 Agent 全链路治理与可观测体系（合规、风控、运维必备）

**技术定义**

1. 输出过滤、内容审核、合规拦截
2. 全链路追踪：工具调用、检索内容、模型输入输出、风控拦截记录
3. 指标监控：幻觉率、情报准确率、抓取成功率、AI 响应耗时
4. 分级告警、台账归档、人工复核工单
5. 权限隔离、数据脱敏、审计日志，满足法务合规举证要求

**本项目匹配情况**

### 1.1.10 本地化轻量模型兜底 + 多模型路由（成本 & 稳定性保障）

# 第二部分：产品概念与 PRD

## 2.1 产品定位与目标用户

### 2.1.1 产品一句话定义

本产品是国内首个**双模式行业智能 Agent**：既可以带零基础创业者快速吃透全行业、零踩坑入行；又可以帮在营创业者从「地域、人文、供应链、渠道、同行、内部链路」全维度诊断困境，输出有优先级的落地整改方案。两套体系共用一套产业底层逻辑，实现从「入行认知」到「经营脱困」的完整创业闭环。

区别于传统「翻页查阅知识库」，本产品为专属行业智能引导 Agent。核心模式为**半对话渐进式引导 + 双向智能指引 + 实时对话复盘总结**。

### 2.1.2 目标用户群体

- **行业新手**：零基础创业者、转行从业人员、调研人员
- **准创业者**：准备入行但缺乏行业认知的人群
- **在营商家**：已开店/已创业的在营经营者，面临经营困境
- **业务操盘人员**：需要系统化行业认知的商业决策者

## 2.2 双模式概述

### 2.2.1 模式 1：入行认知 Agent（准创业者/新手）

**定位**：从零吃透行业全链路、行规、指标、赚钱逻辑、避坑逻辑

**核心目标**：懂行业、能入门、不踩坑、建立完整行业认知

**服务人群**：准创业者、转行人员、行业新人、调研人员、想入行人群

**双轨指引体系（固定不变）**：

| 轨道 | 名称 | 内容 |
|------|------|------|
| 轨道 A | 行业核心关注点（极速入门） | 行业盈利点、亏损坑点、核心指标、账期、淡旺季、行规、风险趋势 |
| 轨道 B | 全链路系统学习（深耕精通） | 原料→生产→品控→仓储→物流→渠道→销售回款，每个节点输出：流程、重点、指标、行规、风险、联动逻辑、小节总结 |

**核心能力**：
1. 半对话分步引导
2. 链路/重点双向穿透
3. 单节点/区间萃取重点
4. 三级总结：节点小结、阶段总结、全行业报告

### 2.2.2 模式 2：经营诊断 Agent（在营商家）

**定位**：基于用户当前真实经营现状，逐层拆解地域、城市、人文、供应链、渠道、同行打法、市场环境、自身短板

**核心目标**：找困境、找原因、找对标、找优先级解决方案、落地脱困

**解决痛点**：
1. 不知道自己为什么不赚钱
2. 不知道是市场问题、地域问题、供应链问题、渠道问题、同行竞争问题
3. 一堆问题不知道先解决哪个
4. 看不懂本地人文、本地市场潜规则、本地同行打法
5. 盲目模仿、盲目投入、越做越亏

**八大维度全场景诊断体系**：

| 维度 | 名称 | 核心内容 |
|------|------|---------|
| 维度 1 | 用户当前经营现状摸底 | AI 分步轻量采集：城市/区县、经营时长、门店/线上模式、营收/利润/客流/转化问题、最头疼的 3 个问题、投入成本/人员情况。建立用户「经营基线」 |
| 维度 2 | 地域 & 城市 & 人文环境诊断 | 行业饱和度、消费人文习惯、本地淡旺季与政策、适合/不适合的经营模式、地域天然优势/劣势 |
| 维度 3 | 本地供应链全链路诊断 | 原料采购成本、供货渠道单一性、仓储/冷链/物流成本对比、供应商潜规则与账期、最优拿货方案 |
| 维度 4 | 全渠道经营诊断（线上+线下） | 线下渠道玩法/选址/客流、团购/短视频流量规则与抽佣、私域运营/复购、投入产出比、流量枯竭/投流浪费 |
| 维度 5 | 同行竞品手段拆解 | 头部同行利润来源/核心优势/垄断手段、腰部主流盈利模式、新手常见错误/倒闭原因 |
| 维度 6 | 内部全链路经营溯源 | 对标标准行业全链路，逐项找偏差：高于行业成本的节点、流失利润的节点、缺失标准动作的节点、踩了隐形坑的节点 |
| 维度 7 | 风险与账期现金流诊断 | 库存积压、坏账、账期错误、备货错误、季节性踩坑、合规风险 |
| 维度 8 | 最终归因 + 优先级排序 | 四类分级：致命级（必须立刻整改，不改持续亏损）、高优级（1-2 周落地，快速提利）、中优级（中长期优化）、观察级（无需改动）。输出：问题原因 + 影响利润比例 + 先后整改顺序 + 具体落地动作 |

**固定诊断顺序**（AI 强制结构化问诊）：

> 用户经营现状录入 → 地域环境诊断 → 供应链诊断 → 渠道诊断 → 同行竞争诊断 → 内部经营链路诊断 → 问题归因排序 → 优先级整改方案

**模式 2 专属输出结构（固定模板）**：

1. 本地市场环境总评（适配度、饱和度、机会点）
2. 你的经营现状与行业标准差距
3. 上游供应链问题清单
4. 渠道 & 流量问题清单
5. 同行竞争压制点
6. 内部链路亏损节点
7. 分级优先级整改方案（唯一落地指导）
8. 短期脱困策略 + 长期稳定经营策略

### 2.2.3 双模式核心设计原则

1. **底层知识库完全共用**：七大产业链路、指标库、行规库、风险库、利润模型、行业周期，两套模式 100% 通用，不重复建库
2. **上层 Agent 逻辑分流**：
   - 模式 1：自上而下教学式引导（行业→链路→重点）
   - 模式 2：自下而上诊断式引导（用户现状→问题定位→链路溯源→解决方案）
3. **双向数据互通**：诊断模式发现的短板自动关联学习模式的对应链路知识点；学习模式掌握的行业规则反向用于经营诊断校验
4. **统一交互形态**：全部采用半对话渐进式 Agent 引导，不刷屏、分步问答、用户轻输入、自动总结、分层输出、按优先级给方案

### 2.2.4 双模式共用底层体系

**100% 共用数据库**：

1. 七大行业全链路流程库
2. 全行业量化指标库（基准值/优秀值/劣质值）
3. 行业隐形行规 & 潜规则库
4. 行业风险坑点库
5. 行业利润结构模型
6. 行业淡旺季周期库
7. 上下游联动传导模型

**双模式统一 AI 能力**：

- 链路区间萃取
- 指标自动对比分析
- 行规风险识别
- 上下游联动推演
- 三级总结报告生成

### 2.2.5 双模式互通逻辑

| 互通方向 | 逻辑 | 效果 |
|---------|------|------|
| 诊断 → 学习 | 诊断发现用户「品控差/供应链贵/渠道不会做」，AI 自动推送对应节点的模式 1 系统化学习内容 | 边诊断、边补课 |
| 学习 → 诊断 | 用户学完行业链路，可一键进入诊断模式 | 自查自纠，对标行业标准找自己的问题 |

### 2.2.6 双模式切换交互设计

**首页双入口**（用户一键选择）：

- 入口 1：【行业快速入行｜新手学习模式】
- 入口 2：【当前经营困境｜诊断优化模式】

**统一对话界面结构**：

1. 顶部：当前模式 + 行业名称
2. 中间：Agent 半对话主交互区
3. 右侧快捷指令（双模式自适应）

**通用快捷指令**：
- 生成本次完整报告
- 总结当前问题/知识点
- 追溯对应行业链路

**模式 1 专属指令**：
- 查看行业核心重点
- 开始全链路系统学习

**模式 2 专属指令**：
- 继续深度诊断
- 查看优先级整改方案
- 查看本地同行打法
- 查看供应链优化方案

**双模式记忆互通**：系统统一保存用户所选行业、学习过的链路、诊断出的问题、整改记录，实现持续迭代、越用越精准。

## 2.5 AI 交互设计规范

### 2.5.1 半对话 Agent 渐进式引导

**核心逻辑**：
1. 不一次性灌输海量信息，Agent 主动分步引导用户、匹配用户需求深浅
2. 所有内容输出分为两大独立且互通的指引体系：
   - 维度一：行业全局「最高频核心关注点」（用户最关心、最赚钱、最踩坑的事项）
   - 维度二：标准全链路逐节点指引（原料→生产→品控→仓储→物流→渠道→销售回款）
3. 支持双向联动：链路节点精准匹配对应核心关注点，实现「看链路懂重点、看重点懂场景」
4. 全程对话可沉淀、可总结、可导出，形成个人行业学习报告

### 2.5.2 标准化引导流程

**步骤 1：行业锚定（Agent 主动引导）**
Agent 主动提问：请选择你需要学习/调研的行业，我将为你提供【行业核心重点速览】和【全链路逐段拆解】两种学习模式。

**步骤 2：需求分层引导（二级精准匹配）**
用户选定行业后，Agent 主动给出双选项：
- 模式 A：行业极速入门（核心关注点优先）——直接输出本行业最大利润点、高频坑点、核心考核指标、行业潜规则、现金流风险、入行门槛
- 模式 B：全链路系统学习（按产业流程逐段拆解）——按七大产业链路，分步引导学习，每学完一个节点自动小结

**步骤 3：双向联动触发（核心特色）**
- 在全链路学习中：用户可随时指令「查看这个节点的核心重点」
- 在核心重点速览中：用户可随时指令「追溯这个重点对应的产业链环节」

**步骤 4：阶段性 & 终局总结**
- 单节点学习总结
- 本次对话阶段性总结
- 完整行业结构化学习总报告（可复制、可导出、可存档）

### 2.5.3 三层对话驱动逻辑

| 层级 | 名称 | 功能 |
|------|------|------|
| 第 1 层 | 主动引导层 | AI 主导节奏，防止用户无目的乱问，标准化学习路径 |
| 第 2 层 | 自由交互层 | 用户可任意提问、跳转、切换模式、指定节点 |
| 第 3 层 | 沉淀总结层 | AI 持续记录上下文，随时输出结构化复盘 |

### 2.5.4 Agent 话术设计规则

1. **通俗化**：摒弃专业晦涩术语，小白可直接听懂
2. **重点高亮**：利润点、坑点、行规、红线统一标记
3. **递进式**：由浅入深，先整体、后局部、再细节
4. **强关联**：每输出一个知识点，自动关联上下游影响

### 2.5.5 上下文记忆规则

AI 永久记忆本次对话：
- 用户选择的行业
- 用户学习过的链路节点
- 用户重点关注的问题（盈利/风险/行规/指标）
- 用户跳过的环节
- 用户重复提问的高频点

记忆用于：最终定制化总结、精准二次指引。

### 2.5.6 AI 核心推理能力

**产业链路传导推理（核心壁垒）**：
AI 内置固定推理公式：上游参数变动 → 中间生产成本变动 → 库存变动 → 物流变动 → 渠道利润变动 → 终端售价变动 → 回款风险变动

支持精准问答：
- "原料涨价 10%，终端利润压缩多少？"
- "品控放宽标准，会带来多少售后成本增幅？"
- "渠道压货 30%，会造成什么连锁崩盘？"

**行业黑话自动翻译系统**：覆盖工厂车间黑话、采购圈暗语、物流包干黑话、渠道返点黑话、销售回款行规黑话。

**AI 自动生成行业学习路径**：自动分层：入门认知层 → 流程精通层 → 指标看懂层 → 行规吃透层 → 商业操盘层。

**AI 错误纠正能力**：自动纠正网络错误行业认知、自媒体错误解读、外行误区。

**指标全自动解析**：每个指标自动输出计算公式、行业基准值、优秀企业值、垃圾企业值、优化方法、影响上下游哪些节点。

## 2.6 数据质量标准

1. **五层数据标准化**：所有节点统一五维字段强制标准化（显性标准层、量化指标层、隐形行规层、风险漏洞层、链路联动层）
2. **信源权重分级**：S/A/B/C/D 五级信源权重自动加权
3. **6 维信息权重优先级**：用户一手经营数据 > 人工情报 > 权威抓取情报 > 行业静态库
4. **情报有效期管理**：短期情报 3 个月过期弱化展示，超 1 年情报归档冷存储
5. **记忆生命周期**：用户对话 90 天自动销毁、加密存储；日志留存 6 个月
6. **多重校验机制**：NLP 语义识别 + 业务规则引擎双重校验；新旧信息冲突七层校验
7. **数据隔离**：本地情报、全国通用知识库、付费情报分库隔离；行业之间数据完全隔离
8. **录入标准化标签**：每一条数据必须带分类标签（公开/内部行规/灰色规则/风险红线、所属链路区间、影响维度、关联指标 ID）
9. **输出证据绑定**：每一段 AI 输出强制挂载情报来源、原文链接、置信度标注
10. **量化指标计算规范**：所有经营诊断量化指标由规则计算，AI 仅做解读，数值结果不依赖大模型生成

## 3.2 半对话引导机制

### 3.2.1 交互核心规则

1. **非一次性输出**：Agent 采用分步提问、分步推送内容，循序渐进，避免信息过载
2. **用户轻反馈驱动**：用户只需简单选择/提问（我要看重点、我要看全链路、我要看某个节点），AI 精准适配
3. **双轨并行机制**：全程保留「核心关注点模式」「全链路拆解模式」自由切换
4. **区间穿透能力**：支持选中单节点/多节点区间，AI 自动提取该区间内所有核心痛点、指标、潜规则、赚钱点
5. **全程记忆沉淀**：Agent 记忆用户学习轨迹、关注重点、提问记录，最终生成结构化总结

**模式 2 半对话 Agent 引导规则**：
1. AI 主动一问一答采集信息，不一次性问完
2. 用户每回答一条，AI 即时分析一条
3. 边采集、边诊断、边输出
4. 最后自动合并生成《经营诊断完整报告》

## 3.3 双维度指引设计

### 3.3.1 维度一：行业全局核心关注点指引（极速入门）

**定义**：跳出流程，直接输出本行业所有人最关心、影响盈利最大、风险最高的核心事项，是行业「干货浓缩库」。

**所有行业统一 8 大核心关注模块（Agent 固定输出模板）**：

| 编号 | 模块 | 内容 |
|------|------|------|
| 1 | 行业核心盈利点位 | 全链路最高利润环节、套利隐形规则、利润浮动影响因素、新手可切入的低门槛赚钱方式 |
| 2 | 行业致命亏损/踩坑点位 | 高频亏损节点、新手通用误区、行业灰色坑/合作骗局/潜规则陷阱、合规红线/监管严查项 |
| 3 | 行业核心考核指标体系 | 全链路 Top10 关键核心指标（用户必须懂）、指标合格/优秀/不及格阈值、指标波动对整体行业的影响 |
| 4 | 行业现金流与账期规则 | 通用结算模式、上下游账期惯例、坏账高发场景、资金积压核心节点 |
| 5 | 行业竞争格局与准入门槛 | 头部玩家垄断环节、新手优势赛道、资金/资源/人脉/技术准入门槛 |
| 6 | 行业淡旺季与周期规律 | 涨价周期、跌价周期、出货高峰期、滞销期、备货/招商/清仓固定周期规律 |
| 7 | 行业隐形行规与默认合作习惯 | 不写在合同里的通用规则、返点/让利/串货/售后默认惯例、圈层合作潜规则 |
| 8 | 行业最新风险与趋势 | 当前行业最大变量、短期洗牌风险、未来 1-3 年核心变化趋势 |

**适用场景**：用户快速入行、快速调研、谈合作、初步判断行业值不值得做。

### 3.3.2 维度二：全链路逐节点系统指引（系统深耕）

沿用产品固定七大通用产业链路，适配所有行业分叉：**原材料→生产加工→品控质检→仓储库存→物流运输→渠道运营→销售回款**

**每个节点 Agent 固定输出结构**：

1. 本节点基础流程简述（通俗化讲解）
2. 本节点专属核心关注点（该区间独有的赚钱点 + 坑点）
3. 本节点关键量化指标
4. 本节点隐形行规
5. 本节点上下游联动影响
6. Agent 自动小节：学完本节点的核心收获

### 3.3.3 核心联动功能：链路区间→精准匹配关注点

用户可自由指令：
1. "帮我提取生产到品控区间所有核心风险"
2. "帮我看渠道 + 销售回款的所有赚钱规则"
3. "汇总仓储物流全节点的隐形行规"

Agent 逻辑：选取指定链路节点/区间 → 调取该区间专属核心关注点 → 合并去重 → 结构化输出专属总结。实现流程和重点完全打通，不割裂。

## 3.4 智能总结能力

### 3.4.1 一级：单节点即时总结

用户学完任意链路节点，AI 自动弹出小结：
【本节点核心总结】核心价值、核心风险、关键指标、隐形规则、联动影响（5 条精简干货）

### 3.4.2 二级：阶段性区间总结

用户指令：「总结当前学习内容」
AI 输出：已学所有节点的合并精华、共性问题、关联逻辑

### 3.4.3 三级：全行业终版总总结

用户指令：「生成行业完整学习报告」
AI 自动整合双维度内容，输出标准化报告：

1. 行业整体概况与准入门槛
2. 全链路各节点核心职责与关键指标
3. 全行业 Top 核心盈利模式汇总
4. 全行业 Top 高频风险坑点汇总
5. 全行业隐形行规汇总
6. 上下游联动核心规律
7. 行业周期与未来趋势
8. 新手入行实操建议

报告结构化、无废话、可直接保存复用。

## 3.5 各 Agent 模块交互流程

### 3.5.1 模式 1 入行认知 Agent 交互流程

1. **行业锚定**：Agent 主动引导用户选择行业
2. **需求分层**：提供双选项——轨道 A（极速入门）或轨道 B（全链路系统学习）
3. **轨道 A 执行**：直接输出 8 大核心关注模块内容
4. **轨道 B 执行**：按七大产业链路分步引导，每节点输出标准六要素（流程、重点、指标、行规、风险、联动），每学完一个节点自动小结
5. **双向联动**：任意模式可随时切换，支持链路→重点追溯、重点→链路追溯
6. **区间萃取**：支持单节点/多节点区间精华提取
7. **三级总结**：节点小结、阶段总结、全行业完整报告

### 3.5.2 模式 2 经营诊断 Agent 交互流程

**固定诊断顺序（AI 强制结构化问诊）**：

1. **用户经营现状录入**（半对话采集）：城市/区县、经营时长、门店/线上模式、营收/利润/客流/转化问题、最头疼的 3 个问题、投入成本/人员情况
2. **地域 & 城市 & 人文环境诊断**：行业饱和度、消费人文习惯、本地淡旺季与政策、适合/不适合的经营模式、地域天然优势/劣势
3. **本地供应链全链路诊断**：原料采购成本、供货渠道单一性、仓储/冷链/物流成本对比、供应商潜规则与账期、最优拿货方案
4. **全渠道经营诊断（线上+线下）**：线下渠道玩法/选址/客流、团购/短视频流量规则与抽佣、私域运营/复购、投入产出比分析
5. **同行竞品手段拆解**：头部/腰部/新手三层打法分析，隐形竞争手段、价格策略、捆绑玩法、获客套路
6. **内部全链路经营溯源**：对标标准行业全链路，逐项找偏差（高于行业成本的节点、流失利润的节点、缺失标准动作的节点、踩了隐形坑的节点）
7. **风险与账期现金流诊断**：库存积压、坏账、账期错误、备货错误、季节性踩坑、合规风险
8. **最终归因 + 优先级排序**：四类分级（致命级/高优级/中优级/观察级），输出问题原因 + 影响利润比例 + 先后整改顺序 + 具体落地动作

### 3.5.3 双维度互通联动逻辑

**关注点 → 追溯链路**：用户查看「行业利润点」，可一键追溯该利润点发生在哪个链路节点、受哪些上游环节影响、影响哪些下游结果。

**链路 → 萃取关注点**：用户学习任意链路，AI 自动萃取当前节点/区间内最值钱、最危险、最关键的核心事项，不用用户自行筛选。

**智能权重排序**：AI 根据行业属性自动权重排序：
- 制造业：优先突出生产、品控、原料重点
- 电商行业：优先突出渠道、投流、逆向售后重点
- 本地生活：优先突出流量、履约、核销、复购重点
- 工程行业：优先突出集采、垫资、回款、质保重点

### 3.5.4 不同行业的 Agent 差异化引导策略

| 行业类型 | 优先推送 | 弱化 |
|---------|---------|------|
| 重制造行业 | 原料波动、生产良率、品控风险、生产成本 | 轻流量运营内容 |

| 生鲜农林行业 | 季节性、损耗率、冷链、产地规则、农残质检 | — |
| 工程跨境行业 | 招投标、垫资、账期、报关、退税、外汇风险 | — |
| 纯服务行业 | 人员履约、服务品控、流量转化、复购回款 | 完全舍弃生产链路 |

## A.1 7 大行业分类体系

底层统一 7 大基础主干：**原料→生产/加工→品控→仓储→物流→渠道运营→销售回款**，针对不同大类行业标注独有分叉节点、删减环节、特殊链路分支、行业专属模块。

### A.1.1 实体制造类

**特点**：重生产，标准完整 7 段全链路。

**子类**：
1. 重工业（钢材、化工原料、机械设备、建材、有色金属）
2. 轻工消费品（家居、五金、塑料件、日用百货）
3. 食品加工（生鲜预制菜、零食、粮油、饮料）
4. 纺织服装（面料、成衣、鞋帽）

### A.1.2 互联网关联实体行业

**特点**：线上流量驱动线下履约，链路分叉最多，软件核心适配赛道。

**子类**：
1. 本地生活实体（餐饮门店、美容美甲、洗车、酒店民宿）
2. 电商实物供应链（3C 数码、美妆、母婴、家居）
3. 生鲜电商实体（果蔬、肉禽、水产）
4. 新能源线下实体（电动车门店、光伏安装、储能设备线下经销）

### A.1.3 农林农牧实体

**特点**：源头生产型，链路上游分叉特殊。

**子类**：
1. 种植类（水果、粮食、中药材）
2. 养殖类（畜禽、水产）

### A.1.4 跨境实体行业

**特点**：基础 7 段主干不变，全链路前后新增进出口分叉。

**子类**：跨境制造出口（玩具、家居、汽配）

### A.1.5 纯线下服务实体

**特点**：无实物生产，链路大幅改造。

**子类**：
1. 教培、家政、维修服务
2. 工程施工（装修、基建）

## A.2 差异化产业链分叉链路清单

### A.2.1 重工业

**通用主干**：原材料开采/化工原料采购→冶炼/合成/机械加工→品控检测→原料/成品仓储→干线整车物流→经销商/工程总包渠道→项目招投标/批量销售+回款

**独有分叉链路**：
1. 上游分叉：矿产开采、危化品原料储备、进口原料报关商检分支
2. 生产分叉：外协铸造/冲压外包、设备维保产线、危废处理子链路
3. 渠道分叉：工程项目集采、招投标流程、垫资供货分支
4. 特殊新增节点：环评、安评、危化仓储、特种设备验收、工程质保回款

### A.2.2 轻工消费品

**通用主干**：化工/金属/木材原料→注塑/组装/打磨生产→成品抽检→成品仓→零担干线物流→多级代理/商超/电商→终端零售回款

**独有分叉链路**：
1. 上游分叉：回收再生料采购分支
2. 生产分叉：OEM 代工、ODM 定制贴牌两条并行链路
3. 渠道分叉：线下商超、线下批发市场、抖音/淘宝电商三条分销分叉
4. 特殊新增节点：包装定制、临期品折价处理、电商退换货逆向链路

### A.2.3 食品加工

**通用主干**：农副产品原料收购→清洗/蒸煮/分装加工→食品质检杀菌→恒温冷链仓储→冷链物流→经销商/商超/餐饮门店→终端售卖回款

**独有分叉链路**：
1. 上游分叉：农产品产地收购、季节性囤货、农残检测前置节点
2. 生产分叉：无菌车间、分装代工厂、废料饲料回收分支
3. 仓储物流专属分叉：冷链温控、冷链中转库、低温配送
4. 特殊新增节点：保质期管控、临期销毁、食药监抽检、餐饮渠道月结账期

### A.2.4 纺织服装

**通用主干**：棉/化纤原料纺纱→织布染色→裁剪缝制成衣→尺寸/面料质检→成衣仓储→物流发货→档口/品牌加盟/电商→终端销售回款

**独有分叉链路**：
1. 上游分叉：面料印染外协、进口面料报关
2. 生产分叉：小单快反工厂、大批量代工两条分叉
3. 渠道分叉：线下批发市场档口、线下加盟门店、直播电商、跨境外贸 4 条链路
4. 特殊新增节点：库存尾货清仓、外贸报关海运、跨境回款结汇

### A.2.5 本地生活实体

**基础主干大幅简化**，无大规模生产环节，链路重构：
流量公域获客（短视频/团购平台）→门店履约服务→店内品控服务标准→门店现货仓储（食材/耗材）→同城短途配送（外卖）→线上团购渠道运营→到店/外卖成交回款

**删减**：完整生产制造链路，替换为「门店服务履约」核心节点

**独有分叉链路**：
1. 上游分叉：食材/耗材集中采购供应链分支
2. 流量分叉：平台团购流量、私域社群、线下自然客流三条获客链路
3. 履约分叉：到店消费、外卖配送两条并行履约分支
4. 特殊新增节点：平台佣金结算、团购核销、差评售后、门店技师排班体系

### A.2.6 电商实物供应链

**通用主干**：工厂原料生产→成品质检→电商云仓仓储→快递分拨物流→电商店铺运营（公域投放）→线上店铺成交+退换货逆向链路+回款

**独有分叉链路**：
1. 上游分叉：自有工厂、一件代发分销、品牌集采三条供货分叉
2. 仓储分叉：厂家仓、第三方云仓、直播间前置仓并行
3. 渠道分叉：直播带货、货架电商、私域分销三条流量链路
4. 逆向专属分叉：退货质检、瑕疵品二次销售、报废处理完整逆向链路
5. 特殊新增节点：平台推广投流、达人坑位费、售后客服、平台保证金结算

### A.2.7 生鲜电商实体

**主干**：产地收购生鲜→分拣初加工→农残品控→冷链仓储→同城冷链配送→线上团购/社区团长渠道→用户自提/配送到家回款

**独有分叉**：
1. 上游：产地代收、冷库囤货、进口生鲜报关
2. 渠道分叉：社区团购团长、线上小程序、线下生鲜门店三条链路
3. 专属节点：损耗分级处理、当日临期折价、团长分佣结算

### A.2.8 新能源线下实体

**主干**：电池/组件原材料→工厂组装生产→设备质检→大件仓储→整车大件物流→线下门店运营/工程渠道→零售/工程安装回款

**独有分叉**：
1. 渠道分叉：线下门店零售、政企工程集采、线上线索引流到店
2. 特殊节点：上门安装履约、售后维修链路、质保理赔、充电桩配套供应链

### A.2.9 种植类

**主干**：种苗/化肥农资采购→田间种植管护→农产品采摘初加工→农残质检→保鲜仓储→产地物流→批发商/电商渠道→终端销售回款

**独有分叉**：农资采购、季节性采收、产地代收代办、烘干加工外协分支

### A.2.10 养殖类

**主干**：饲料/种苗采购→养殖繁育→屠宰/捕捞加工→检疫品控→冷链仓储→冷链物流→批发市场/餐饮渠道回款

**独有分叉**：疫病防疫、屠宰外协、生鲜冷冻两条仓储分叉

### A.2.11 跨境制造出口

**基础 7 段主干不变**，全链路前后新增进出口分叉：
原料采购→生产制造→品控（商检）→保税仓仓储→海运/空运跨境物流→海外经销商渠道→海外终端销售+外汇回款

**独有分叉**：
1. 前置：海关商检、保税区仓储、退税流程
2. 物流分叉：海运整柜、空运、国际快递三条分支
3. 回款分叉：信用证结汇、跨境对公打款、海外代理账期

### A.2.12 教培、家政、维修服务

**无原料、生产、仓储节点**，重构链路：
师资/服务人员储备→服务标准品控→线上平台流量运营→上门/到店服务履约→客户付费回款

**独有分叉**：线上短视频引流、本地社群分销、线下门店拓客三条流量分支

### A.2.13 工程施工

**主干**：建材原料采购→现场施工制造→工程验收品控→建材临时仓储→短途工地物流→工程渠道投标→项目分期回款

**独有分叉**：分包外协、工程垫资、质保尾款、材料损耗处置分支

### A.2.14 统一链路差异化规则

1. 通用 7 大主干为系统默认模板，每个行业可开启/关闭节点，支持新增行业专属子链路
2. 互联网关联实体行业共性改动：
   - 新增「线上流量运营」前置分叉节点
   - 新增「逆向退换货/售后履约」独立子链路
   - 渠道层拆分为「公域平台、私域、线下门店」三条并行分支
3. 重生产制造业：完整保留 7 段主干，上游拓展原料开采、外协加工分叉
4. 本地生活服务业：删除生产制造主节点，替换为「门店服务履约」模块
5. 跨境类行业：全链路首尾新增报关、保税仓、外汇结算专属分叉
6. 农林生鲜类：上游增加种养管护季节性分支，仓储强制配套冷链子节点
