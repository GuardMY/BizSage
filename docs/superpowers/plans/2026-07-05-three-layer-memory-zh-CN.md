# 三层记忆实现计划

> **面向 Agent 执行者：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans` 按任务逐项落实本计划。步骤使用复选框（`- [ ]`）语法进行追踪。

**目标：** 为 BizSage 构建短期会话记忆、长期用户记忆，以及自动摘要与遗忘机制；以 MySQL 作为事实来源，以 Qdrant 作为可选语义侧车。

**架构：** API 服务负责持久化、访问控制、生命周期规则和会话 API。AI worker 负责记忆组装、记忆候选提取、语义召回和摘要生成。Web 端继续只调用 API，并通过持久化消息而不是仅本地状态获得连续对话体验。

**技术栈：** Spring Boot、JdbcTemplate、H2/MySQL schema SQL、FastAPI、pytest、Qdrant、Next.js、Node tests。
