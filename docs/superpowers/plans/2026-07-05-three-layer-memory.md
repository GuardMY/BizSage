# Three-Layer Memory Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build short-term conversation memory, long-term user memory, and automatic summarization/forgetting for BizSage using MySQL as the source of truth and Qdrant as an optional semantic sidecar.

**Architecture:** The API service owns persistence, access control, lifecycle rules, and conversation APIs. The AI worker owns memory assembly, memory extraction candidates, semantic recall, and summary generation. The web app continues to talk only to the API and gains visible conversation continuity from persisted messages rather than local-only state.

**Tech Stack:** Spring Boot, JdbcTemplate, H2/MySQL schema SQL, FastAPI, pytest, Qdrant, Next.js, Node tests.
